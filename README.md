# waymakr-sms-data

Data feed for the WayMakr SMS text line — refreshed snapshots of verified NYC help programs.

WayMakr's text line answers with the same source-checked listings as [waymakrnyc.org](https://waymakrnyc.org). This repository holds the snapshot files the text line reads from: program name, provider, borough, contact and access details, the official source, and the date each listing was last checked.

Listings are checked against their official sources only. When a source changes, the snapshot is refreshed — a listing is never carried on an old check.

Part of WayMakr NYC — free crisis help in New York City. Here, no one walks alone.
